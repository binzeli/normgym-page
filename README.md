# NormGym project page

Static project page for *NormGym: Evaluating Normative Competence through Social Interaction*.

No build step. Everything is in `index.html` and `static/`.

## Preview locally

    python3 -m http.server 8000

Then open http://localhost:8000.

## Deploy

Push to GitHub, then go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
